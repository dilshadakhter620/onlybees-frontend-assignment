# OnlyBees Ticket Selection UI (React)

This project is a frontend UI clone of the OnlyBees event ticket selection page, built as part of a frontend assignment. It demonstrates React fundamentals including state management, API integration, and dynamic UI updates.

---

## 🚀 Tech Stack
- React (Vite)
- JavaScript (ES6+)
- HTML5
- CSS3

---

## 📌 Features
- Fetches ticket section data from OnlyBees API
- Displays ticket price and availability dynamically
- Increment / decrement ticket selection
- Calculates total ticket count and price in real time
- Checkout summary bar
- Loading state handling
- Fallback mock data if API fails

---

## 🔗 API Used
https://concertsapi.onlybees.in/api/sections/availability
